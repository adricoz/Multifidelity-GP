## Vue d'ensemble

- **Objectif** — Implémentation d'un processus gaussien multi-fidélité non imbriqué (NN-MF-GP) et d'un algorithme d'optimisation globale efficace (EGO) selon Sacher et al. (2021) (`references/multifidelity_opt.pdf`). La formulation récurrente provient de la thèse de L. Le Gratiet (2013) (`references/Multi_fidelity_Gaussian_process_regressi.pdf`). Le cadre vise l'accélération de calculs de dynamique des fluides mais reste général pour tout problème où le coût de calcul est le facteur décisionnel.

- **Architecture**
  - `mfego/` — cœur du framework : `src/` contient `optimizer.py`, `acquisition.py`, `cokriging.py`, `kernels.py` ; `main.py` exécute l'exemple Forrester 1D.
  - `example/` — applications pratiques : `cokriging/` (surrogat Forrester 1D), `hartmann_6d/` (optimisation EGO), `hydrofoil_optim/` (minimisation de traînée via `neuralfoil`).
  - `benchmarks/` — comparaison avec BoTorch, scikit-learn, SMT ; sous-dossiers `cokriging/`, `surrogate_v2/`, `surrogate_v3/` ; fichiers partagés `bench_lib.py`, `figure_style.py`.
  - `pipelines/` — orchestration de l'optimisation de profils d'aile via `bdtoolbox_foil/` (`run.py`, `simulator.py`, `solvers.py`) et les solveurs bdToolbox/bdFoil.
  - `studies/` — pipelines d'optimisation sur la section C-foil Intens SY (`cfoil_intens_kulfan`, `cfoil_intens_kulfan_trim`, `cfoil_intens_kulfan_trim_2`).
  - `legacy/` — code historique : `legacy_mfego_initial/`, `legacy_nested/`, `legacy_non_nested/`.
  - `analysis/` — scripts de diagnostic et rapport `RAPPORT_ANALYSE.md` documentant toutes les corrections (`# [FIX-<ID>]`).
  - `sandbox/` — carnet d'expérimentation (Bayes mono-fidélité et N-MF sur Hartmann 6D).
  - `tests/` — tests unitaires orchestrés par `conftest.py`.

- **Points d'entrée**
  - `cd mfego && python main.py`
  - `python -m example.hartmann_6d.hartmann_6d`
  - `python -m example.hydrofoil_optim.hydrofoil_optim`
  - `python example/cokriging/main.py`
  - `python -m pytest` (ou `python -m pytest -m "not slow"`)
  - `benchmarks/hartmann_benchmark.ipynb` (kernel dédié `.venv-benchmark`)
  - `python -m pipelines.bdtoolbox_foil.run --config pipelines/configs/section2d_naca_3levels.json`

- **Dépendances principales** — `example/`, `pipelines/`, `studies/`, `benchmarks/` et `tests/` dépendent tous de `mfego/src/`. `benchmarks/` requiert un environnement virtuel dédié (`.venv-benchmark`, `requirements-benchmark.txt`). `pipelines/` relie `mfego` aux solveurs bdToolbox/bdFoil (environnent conda `bdToolbox`).

- **Points notables** — `runs/` (sorties de chaque exécution) sont ignorées par `.gitignore` ; `legacy/` conserve le code initial non corrigé ; `analysis/RAPPORT_ANALYSE.md` est la référence pour chaque correction ; `sandbox/` sert de terrain d'expérimentation informel.
